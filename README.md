# Маргиналии

Локальный веб-инструмент для рецензирования Markdown-документов, подготовленных ИИ-агентами. Исходный документ показывается справа с номерами физических строк, а замечания собираются слева и экспортируются как один читаемый Markdown-файл.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm install
npm run dev
```

Откройте адрес, который напечатает Vite. Документы читаются через браузерный выбор файла и не загружаются на сервер. Состояние хранится только в памяти текущей вкладки.

## Проверка

```sh
npm test
```

Команда запускает модульные проверки, производственную сборку и браузерные сценарии Playwright.

## Правила рецензии

- Замечания с привязкой автоматически упорядочиваются по строке, положению начала и конца выделения, затем по времени создания.
- Многострочное выделение экспортируется как `### Строки N–M · Тип`.
- Общая запись не получает фиктивную строку. Она сохраняет выбранное место между замечаниями, даже если привязанные замечания позже добавлены или удалены.
- «Скопировать рецензию» и «Сохранить .md» формируют один и тот же текст.
- Загруженный Markdown не исполняет HTML или JavaScript и не загружает встроенные изображения.
